# Code of Conduct

## In short

Be decent. Assume the other person is trying to get something right.

## Expected behaviour

Engage with the technical substance. Criticise methods, results and code rather than people. When you
disagree about a number, reach for the evidence — a test case, a reference, a derivation — rather than
for volume. Accept that other people have constraints you cannot see.

## Unacceptable behaviour

Harassment, personal attacks, discriminatory language, deliberately derailing discussion, or
publishing others' private information.

## Scope

This applies in the issue tracker, in pull requests, in commit messages and anywhere else this project
is represented.

## Enforcement

Report a problem to sreeramanil30@gmail.com. Reports are handled confidentially. The maintainer may edit, hide or
delete contributions that violate this document, and may block persistent offenders.

This is a small project maintained by one person; expect a human response rather than a process.
